# GitTrainingDemo

Project .NET console sederhana untuk latihan Source Control (Git & Bitbucket) — Day 2 Backend Bootcamp.

## Struktur

- `GitTrainingDemo/Services/UserService.cs` — logic login sederhana.
- `GitTrainingDemo/Services/OrderService.cs` — kalkulasi total pesanan.
- `GitTrainingDemo/appsettings.json` / `appsettings.Development.json` — konfigurasi aplikasi.
- `index.html` — halaman login sederhana.

## Menjalankan project

```bash
cd GitTrainingDemo
dotnet run
```
